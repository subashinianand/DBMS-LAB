# README – SQL Lab Programs

## Aim
To practise basic SQL queries using the MySQL database.

## Programs
1. Create Database and Table
2. Insert Records
3. Simple SELECT Queries
4. Sorting and Filtering
5. Aggregate Functions
6. GROUP BY and HAVING
7. Constraints
8. Indexing
9. Set Operators
10. String and Date Functions
11. Transactions

## Software Required
MySQL Workbench or MySQL Command Line.

## Procedure
1. Create the database and tables.
2. Insert records into the tables.
3. Execute the SQL queries for each program.
4. Observe the output.

## Result
Successfully executed the SQL lab programs and practised basic SQL queries and database operations.
